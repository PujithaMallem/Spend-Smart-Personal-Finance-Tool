# 💰 SpendSmart – Budget & Expense Tracker

**SpendSmart** is a lightweight, responsive web application designed to help users manage their personal finances by tracking income, expenses, and budget limits. Built using **HTML, CSS, JavaScript**, and **JSON** (local storage), it offers a clean interface and real-time analytics to promote smarter spending habits.

---

## ✨ Features

- 📊 Track income and categorized expenses
- 🧮 Calculate total balance, income, and spending
- 📁 Data stored in browser via JSON (Local Storage)
- 📉 Real-time visual updates to budget usage
- 🎨 Responsive design using HTML5 & CSS3
- 🚫 Delete or edit individual transactions
- 📱 Mobile-friendly interface

---

## 🌐 Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Data Handling:** JSON (Local Storage)
- **Frameworks/Libraries:** None — Vanilla JS  
- **Deployment:** Static Web App (GitHub Pages/Netlify supported)
